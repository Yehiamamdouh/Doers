# منصة اختبارات MCQ تفاعلية

موقع مستقل (لا علاقة له بموقع Doers) لحل أسئلة الاختيار من متعدد. فيه حسابات للطلاب، واشتراك مدته 3 شهور يبدأ من أول تسجيل دخول.
مكتوب بـ PHP وSQLite، ولا يحتاج قاعدة بيانات MySQL ولا خطوة build.

## المميزات

**للطالب** (`index.php`)
- يختار الإجابة فيظهر فوراً إن كانت صحيحة: كارت السؤال يتلون بالأخضر لو صح وبالأحمر لو غلط، وتظهر الإجابة الصحيحة مع الشرح.
- شريط تقدم وعداد للصحيح والخطأ، وأرقام الأسئلة ملونة للتنقل بينها.
- شاشة نتيجة بالنسبة المئوية، واحتفال (confetti) عند 80% فأكثر، ومراجعة كاملة لكل الأسئلة مع فلتر للأخطاء.
- "حل أخطائي فقط": محاولة جديدة فيها الأسئلة الغلط وغير المحلولة من آخر محاولة.
- يكمل من حيث توقف، ووضع ليلي/نهاري، ومناسب للموبايل.
- لو السؤال بالإنجليزي يُعرض من الشمال لليمين، ولو بالعربي من اليمين للشمال.

**الاشتراك**
- يبدأ عدّ 3 شهور (قابلة للتغيير من الإعدادات) **من أول تسجيل دخول** للطالب.
- عند انتهاء المدة يُقفل الحساب تلقائياً، حتى لو كان الطالب داخل المنصة وقتها، وتظهر له شاشة "انتهى الاشتراك" مع زر واتساب للتجديد.
- قبل الانتهاء بـ 7 أيام يظهر للطالب تنبيه باللون الأصفر.
- القفل يعمل على السيرفر، فلا يمكن تجاوزه من المتصفح.
- جهاز واحد لكل طالب (اختياري): الدخول من جهاز جديد يُخرج الجهاز القديم، لمنع مشاركة الحساب.

**للمعلم** (`admin.php`)
- إضافة طالب أو مجموعة طلاب (الاسم + الرقم) مع توليد كلمة مرور، وزر لإرسال بيانات الدخول على واتساب.
- لكل طالب: تجديد 3 شهور، أو إنهاء الاشتراك الآن، أو إعادة ضبط (يبدأ من الدخول القادم)، أو تحديد تاريخ انتهاء يدوي. ويمكن أيضاً إيقاف الحساب أو حذفه، أو تسجيل خروجه من كل الأجهزة.
- **استيراد الأسئلة من PDF**: ترفع الملف فيُستخرج النص في المتصفح، ثم يحلله النظام إلى أسئلة واختيارات وإجابة صحيحة وشرح. تراجع الأسئلة قبل الإضافة.
- محرر يدوي للأسئلة، وتصدير/استيراد JSON.
- صفحة نتائج لكل الطلاب مع تصدير Excel (CSV).

## شكل الأسئلة الذي يفهمه المحلل

```
1. Incidence rate measures:
A) Existing cases
B) New cases
C) Deaths
D) Recoveries
Answer: B
Explanation: Incidence counts new cases in a period.

س2: ما هي عاصمة مصر؟
أ) الإسكندرية
ب) القاهرة *
ج) أسوان
الشرح: القاهرة هي العاصمة.
```

- الترقيم يمكن أن يكون بأي شكل من `1.` و`1)` و`1-` و`Q1` و`س1`. والاختيارات بـ `A-J` أو `a)` أو `(a)` أو `أ-د`، وقد تكون في سطر واحد.
- الإجابة الصحيحة تُكتب في سطر `Answer:` أو `الإجابة:`، أو بعلامة `*` أو `✓` بجانب الاختيار. ويمكن وضع مفتاح إجابات في آخر الملف (`Answer Key` ثم `1-B 2-C …`) أو لصقه في خانة منفصلة.
- **ملفات PDF المصوّرة (سكان) لا تحتوي على نص.** تحتاج أولاً أداة OCR (مثل Google Drive: افتح الملف بـ Google Docs)، ثم الصق النص.

## الرفع على الاستضافة (cPanel / Namecheap)

1. ارفع محتويات فولدر `mcq-platform/` كما هي على دومين أو ساب دومين، مثل `exams.example.com`، أو داخل فولدر.
2. يحتاج PHP 8.1 أو أحدث مع `pdo_sqlite`، وهو مفعّل افتراضياً في أغلب الاستضافات.
3. تأكد أن PHP يستطيع الكتابة في فولدر `data/`، ففيه تُحفظ قاعدة البيانات `platform.sqlite`.
4. **افتح `admin.php` فوراً** وأنشئ حساب المعلم. هذه الشاشة تظهر مرة واحدة فقط، لأول من يفتحها.
5. من الإعدادات: اكتب اسم المنصة ورقم واتساب التجديد.
6. فعّل HTTPS (شهادة SSL مجانية من cPanel).

الملفات `.htaccess` تمنع الوصول المباشر لـ `data/` و`lib/` على Apache/LiteSpeed. لو السيرفر Nginx، امنع المسارين يدوياً.

**النسخ الاحتياطي:** كل البيانات في ملف واحد هو `data/platform.sqlite`. انسخه دورياً.

## التشغيل محلياً

```bash
cd mcq-platform
php -S 127.0.0.1:8000
# الطلاب: http://127.0.0.1:8000/   المعلم: http://127.0.0.1:8000/admin.php
```

## الملفات

| الملف | الدور |
|---|---|
| `index.php` | صفحة الطلاب |
| `admin.php` | لوحة المعلم |
| `api.php` | كل العمليات (JSON): الدخول والاشتراك والإجابات والإدارة |
| `lib/bootstrap.php` | قاعدة البيانات والجداول والإعدادات والجلسات |
| `assets/student.js` | واجهة الطالب |
| `assets/admin.js` | لوحة المعلم واستيراد PDF |
| `assets/parser.js` | تحويل النص إلى أسئلة |
| `assets/vendor/pdfjs/` | pdf.js 3.11.174 لقراءة PDF في المتصفح (مستضاف محلياً) |
